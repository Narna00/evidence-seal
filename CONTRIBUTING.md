# Contributing

Describe the operational problem and provide a synthetic reproducer. Keep network activity out of these offline tools. Changes to a decision rule need regression coverage for the expected behavior and at least one failure or boundary case.

Run `python -m unittest discover -v` on Python 3.12 or later. Use only fabricated evidence and documentation-only target addresses. Do not submit client artifacts or unreviewed standards text. Keep output schemas stable or explicitly version breaking changes.

Security reports belong in the channel described in SECURITY.md.
